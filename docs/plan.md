# 现实循环切片机 · 开发计划

对应 02-后备点子 #8（2026-10-29 选定）。四项硬要求见 00 与 24 号纲领：大众审美 UI/零学习成本、零基础 PDF 说明书、傻瓜式安装+标准卸载、移动端评估+APK。

## 产品定义

从用户的一段视频里找出"最适合无缝循环"的片段，生成动态壁纸素材。例：咖啡热气、雨中窗户、树影。

## 核心引擎（真实算法，不许预置假结果）

1. 解码：`<video>` 逐帧 seek（0.1s 步长）→ canvas 抽帧为 160×90 灰度缩略序列（内存保护：源视频 ≤60s；超长提示裁剪）。
2. 候选窗口：时长 1.5–6s，滑动窗口；每窗口评分 = 首尾帧差异（越小越好）×窗口内运动量（太小=死画面，太大=跳变）加权。
3. 边界融合：窗口末尾 N 帧（0.3s）与开头交叉溶解（crossfade），溶解权重线性。
4. 导出：canvas 逐帧绘制 + `MediaRecorder`（canvas.captureStream 60fps）重编码为 WebM（VP9/VP8）；导出为实时时长（6s 循环约需 6s），进度如实显示。
5. 诚实边界：输出仅 WebM；实时导出耗时≈素材时长；首尾溶解在运动剧烈画面会有轻微重影——界面注明。

## UI（大众审美 + 零学习成本）

浅色主题；三步：导入视频 → 自动推荐 3 个最佳循环片段（可微调滑块）→ 预览循环效果并导出。全程无术语。
